    §3 如何套用到 v83.idb¶

    方法 A:在 IDA Pro GUI 內套用 IDC script¶

    File → Script file → 選擇 diamondo25 的 .idc → Run

    注意:Angel 的 ToolTip addresses 是基於 32-bit v83 client 偏移,在 IDA 9.x 的 64-bit IDB 中可能需要 base address 重新計算
