    W18　產品演進與完結展示¶

    本頁為主題式重組，內容全部來自原始的 42 份逐片教學筆記，未引入外部資訊。 每條可獨立引用；條目 ID 穩定，請勿隨意改號。

    ⚠️ 本頁來源的特殊限制：完結片（U36）全片無任何語音（兩段音軌 transcription 皆為 [No speech]），所以這一頁所有敘述都只代表「畫面上看得見的東西」， 無法核對講者說了什麼、也無法判斷畫面理解結果本身是否正確。

    條目¶

    W18-001　完結片沒有任何可學的程式碼或指令¶

    • 關鍵字：[No speech] Milestone 無程式碼 無終端機指令
    • 來源：完結片 全片（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：這不是教學片，是完結成果展示（Showcase）。畫面理解結果明確記載 「本影片純粹是專案開發過程中的 Milestone 展示……過程中並無程式碼層面的教學」。 全片未出現任何 Java 原始碼撰寫、編譯或終端機指令；唯一的「程式碼」是查閱 WZ 資源檔 Eqp.img.xml 以取得道具 ID。若預期從完結片取得「從 0 開始」的實作步驟，會落空。 素材中也沒有找到可辨識的完結發言、訂閱宣傳或片尾話術，畫面結尾是佔位頁與 IDE 停止程式運行。
    • 相關：見 W13（打包與部署）——真正的收尾工序在那一頁
    • 坑：（本條未發現坑）

    W18-002　重構前舊版控制台：按鈕式介面＋彈出視窗改設定¶

    • 關鍵字：HeavenMS-Vop V001 (2021) 服务启动 GM指令 修改内容 监听端口: 8484 GMS.exe
    • 來源：完結片 00:00–02:40（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：前半段展示 2021 年的舊版控制台。左側導覽列五個按鈕： 服务启动、服务配置、角色管理、GM指令、停止服务。 點「服务启动」→ 右側大量印出伺服器啟動日誌（加載掉落物、生成點、任務腳本等）， 日誌最後出現 监听端口: 8484。 點「服务配置」→ 切換為 Table，欄位為 分组、类型、变量名、当前值、描述， 可見範例列 分组 = ChannelServer、变量名 = net.sf.odinms.channel.net.port； 雙擊某一行會跳出標題為「修改内容」的彈出對話框。 接著開啟資料夾 gmd011-client-master 執行 GMS.exe，登入角色進入地圖「射手村」。 回到控制台點「GM指令」→ 依提示輸入玩家名 → 出現欄位為 指令ID、指令名、参数格式 的指令列表 → 選「刷出怪物」並填怪物 ID 與數量送出 → 遊戲畫面中怪物出現在角色旁邊，證明控制台與伺服器連動正常。
    • 坑：舊版設定只能靠彈出視窗改，改完沒有統一的「保存」動作（對照 W18-003 的改進）。

    W18-003　重構後的三大改動：內聯編輯、卡片化、Loading 流程¶

    • 關鍵字：Inline Editing world.serverMessage 保存修改 恢复默认 刷出物品 Loading... 服务启动中 Toggle
    • 來源：完結片 02:41–04:00（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：新版沿用 HeavenMS-Vop V001(2021) 標題但改為現代扁平化外觀。三個明確改動：
    • 服務配置改為表格儲存格內聯編輯（Inline Editing）——取消舊版彈出視窗，直接雙擊儲存格輸入， 畫面上被編輯的變數是 world.serverMessage；頂部新增快速操作按鈕 新增配置、刷新表格、保存修改、恢复默认。
    • GM 指令從文字表格改成大型圖文卡片按鈕——可見 刷出物品、刷出怪物、发送全服公告、 给玩家发点券、发送全服邮件、给玩家发物品。
    • 啟動流程加入設定頁與讀取動畫——在含「数据库名称」設定的頁面點「确认启动服务」， 畫面中央出現 Loading... 服务启动中，之後在「运行日志」頁籤看到啟動日誌； 導覽列縮減為 运行日志、服务配置、游戏管理，伺服器開關改為右上角的 Toggle 元件。
    • 程式碼：
    # 服務配置表格中的變數（分组 / 类型 / 变量名 / 当前值 / 描述）
ChannelServer
net.sf.odinms.channel.net.port
world.serverMessage

# 讀取動畫
Loading... 服务启动中
    • 坑：改完一定要按「保存修改」並確認（确认保存修改吗？ → 确定），只做內聯編輯不儲存等於沒改。 舊版 停止服务 按鈕在新版被 Toggle 取代，舊的教學步驟不能直接沿用。

    W18-004　新版 HeavenMS Top 控制台：八個分頁與已實測功能¶

    • 關鍵字：HeavenMS Top 控制台 账号管理 角色管理 家族管理 商城管理 修改密码 踢下线 封号管理
    • 來源：完結片 04:00–06:00（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：尾段實測第三個介面 HeavenMS Top 控制台，八個分頁： 基础设置、账号管理、角色管理、家族管理、背包管理、技能管理、邮件管理、商城管理。 實測結果：
    • 角色管理：讀取到在線角色（账号: admin、角色: 小睡...），右鍵選單為 踢下线、发送道具、发送金币、发送点券、发送抵用券、封号管理；實測 发送道具 成功（发送成功）。
    • 账号管理：右鍵 解封、封号、修改密码、删除账号；實測重置密碼（确认要重置该账号的密码吗？ → 重置成功）。
    • 家族管理：展示 增加家族 與右鍵 解散家族 的 UI 互動。
    • 商城管理：顯示 功能还在开发中，敬请期待！，未完成。
    • 背包管理／技能管理／邮件管理：僅出現分頁，未實測。 伺服器端日誌可見判定上線的關鍵字：玩家 1 在线状态：1。
    • 程式碼：
    2024-01-16 21:57:13.250 [INFO] ---> 玩家 1 在线状态：1
2024-01-16 21:57:13.266 [INFO] ---> 玩家 1 发送物品成功: 1010000 数量: 1
...
2024-01-16 22:00:15.539 [INFO] ---> 断开连接...
Process finished with exit code 0
    • 坑：商城管理 的佔位頁不是 bug，是尚未實作。不要把完結片當成「所有分頁都能用」的功能清單。

    W18-005　查道具 ID 要看 WZ 的 Eqp.img.xml，控制台輸入要去前導零¶

    • 關鍵字：Eqp.img.xml WZ 01010000 1010000 wz/String.wz 道具 ID
    • 來源：完結片 04:00–06:00（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：本片示範的唯一「查檔」動作是取得道具 ID。檔案路徑 HeavenMS-App/wz/String.wz/Eqp.img.xml（專案樹中位於 wz 資料夾下）， 內容是 WZ 資源的 XML 中繼格式。反白節點取出道具 ID 為 01010000（8 碼）， 但後續在控制台輸入時省略前導零，輸入 1010000。 這是全片唯一能算「查資料」的技巧，之後要用控制台發物品、卷軸都要回來查這裡。
    • 程式碼：
    <imgdir name="01010000">
    <string name="name" value="力量印记" />
    <string name="desc" value="象征力量的红色印记。可装备在平时不可见的肉眼周围。使它具有各种神奇的升级次数。" />
</imgdir>
    • 坑：道具 ID 前導零陷阱——WZ 裡是 8 碼 01010000，控制台要用 1010000。 位數填錯很可能直接落到 请确认角色是否在线或者此道具在当前版本是否存在 這個錯誤。

    W18-006　「角色離線或道具不存在」是同一個錯誤訊息¶

    • 關鍵字：请确认角色是否在线或者此道具在当前版本不存在 防呆 在线状态
    • 來源：完結片 04:00–06:00（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：在未開啟遊戲客戶端時點擊「发送道具」並輸入道具 ID 1010000， 錯誤訊息對話框原文為 请确认角色是否在线或者此道具在当前版本不存在。 開啟客戶端登入後，同樣的操作就成功。這是伺服器端的保護機制（防呆）。
    • 坑：該錯誤訊息把兩個原因混在一起（角色離線 或 道具在當前版本不存在）， 除錯時容易被誤導——畫面中實際原因就只是角色未上線。 排查順序應該是：先看日誌有沒有 玩家 1 在线状态：1，再懷疑道具版本。

    W18-007　新舊兩版介面功能對照¶

    • 關鍵字：服务配置 运行日志 游戏管理 指令ID 参数格式 数据库名称
    • 來源：完結片 00:00–04:15（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：三個介面版本的功能差異，可直接當作「產品演進路線圖」看：
    功能 重構前 重構後
    導覽列 服务启动／服务配置／角色管理／GM指令／停止服务 运行日志／服务配置／游戏管理（＋顶部分頁「启动」）
    服務配置修改 雙擊列 → 「修改内容」彈出視窗 雙擊儲存格內聯編輯 ＋ 顶部「保存修改」
    配置輔助按鈕 無 新增配置／刷新表格／保存修改／恢复默认
    GM 指令呈現 文字表格（指令ID／指令名／参数格式） 大型圖文卡片按鈕
    啟動流程 直接按「服务启动」 設定頁（含数据库名称）→「确认启动服务」→ Loading
    伺服器開關 「停止服务」按鈕 右上角 Toggle 元件
    • 相關：見 W08（配置管理）、W11（指令管理）
    • 坑：新版與舊版介面並存且標題極相近——HeavenMS-Vop V001 (2021) 與 HeavenMS-Vop V001(2021) 僅差一個空格，示範或截圖時容易開錯版本。尾段的 HeavenMS Top 控制台 又是第三個視窗標題。

    W18-008　實測時的三個硬性前提¶

    • 關鍵字：gmd011-client-master 073.client.master v073 射手村 保存修改
    • 來源：完結片 00:00–06:00（無口述，純畫面）｜U36_完结片_教學筆記.md
    • 要點：要重現完結片的聯動測試，三件事必須成立：
    • 客戶端版本要對得上——前半段用 gmd011-client-master（內含 GMS.exe）， 尾段改用 <DRIVE>\pms\073.client.master（v073 客戶端）。兩份不一致，WZ 資源與客戶端版本對不上就會觸發防呆錯誤。
    • 角色必須在線——控制台讀取的是線上角色列表，離線狀態下無法對角色下指令； 且客戶端必須成功進入遊戲世界（射手村）才會處於「在线状态：1」。
    • GM 指令參數依指令而異——「刷出怪物」需怪物 ID 與數量，指令列表的「参数格式」欄是唯一依據。
    • 坑：只做內聯編輯不按「保存修改」，設定不會生效（見 W18-003）。 這三條都是「看起來做了但沒生效」的無聲失敗，排查成本高，值得先記住。
